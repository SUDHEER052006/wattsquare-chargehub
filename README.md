# WattSquare ChargeHub

Landing page for **WattSquare ChargeHub LLP** — ultra-fast EV charging
infrastructure on the highway corridors of Andhra Pradesh and Telangana.

**Live site:** https://sudheer052006.github.io/wattsquare-chargehub/

## What this is

A single self-contained `index.html` — no build step, no framework, no
dependencies beyond Google Fonts. Open the file and it runs.

| | |
|---|---|
| Page | `index.html` (~127 KB, inline CSS + JS) |
| Images | `assets/` |
| Fonts | Inter + Sora (Google Fonts) |
